# Archive — frozen spec history

Everything under this directory is **frozen history**. It is not maintained
and not kept in sync with the code.

- `specs/` — the legacy design corpus (`0001-direct-deploy` + the
  `direct-deploy/` stage specs, incl. TEST-SPECS). Superseded as the
  requirement source.
- `drafts/` — superseded drafts (migration-plan) and unimplemented ones
  (0002 transitive cache, 0003 smart GC — "not implemented, awaiting
  decision" status notes inside).

The canonical, maintained requirement corpus is
[`openspec/specs/`](../../openspec/specs/) (capabilities, updated through
openspec changes). Documentation under
[`doc/user_guide/`](../user_guide/) and
[`doc/technical_details/`](../technical_details/) links there; links into
this archive appear only as historical supplements.
